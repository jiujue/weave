# weave-demo-react

React demo: Data and forms are controlled by React, with a split-screen display of two scene construction methods on the right (`sceneFromJSX` vs `@jiujue/weave-types` JSX runtime).

## Running

In the repository root:

```bash
pnpm install
pnpm dev:react
```

## Related Packages

- `@jiujue/weave-app`
- `@jiujue/weave-react`
- `@jiujue/weave-types`
