## core：容器滚动条（右侧 + 底部）

* 在 container 的 `buildDisplayList()` 分支实现滚动条 overlay：

  * 关键点：滚动条必须画在“视口坐标系”，不能跟着 `translate(-scroll)` 一起移动

  * 因此会调整 container 的子节点绘制：

    * `save + translate(frame)`

    * `clipRect(0,0,w,h)`（overflow != visible）

    * `save + translate(-scrollX,-scrollY)` → 绘制 children → `restore`

    * 计算 thumb 尺寸/位置后绘制滚动条（track + thumb）

    * `restore`

* 滚动条几何（默认样式）：

  * thickness：8（可后续抽配置）

  * 竖条：x = w - thickness - inset，y=inset，h = h - 2\*inset

  * 横条：y = h - thickness - inset，x=inset，w = w - 2\*inset

  * thumbLen = max(minThumb, viewport/content \* trackLen)

  * thumbPos = (scroll/maxScroll) \* (trackLen - thumbLen)

  * 仅当 `maxScroll>0` 且 overflow 为 `auto|scroll` 时绘制

## core：横向滚动（container）

* 现有逻辑已支持 `overflowX`/`scrollX` 影响 children 的 `translate(-scrollX)`；会补齐：

  * 滚动条 bottom 渲染

## core：Table 滚动（竖向 + 横向）

* Table 的滚动设计：header 竖向固定（sticky），行区竖向滚动；横向滚动影响 header+body。

* 在 table paint 分支内计算 scroll meta 并 clamp：

  * contentWidth = totalW（列宽总和）

  * bodyTotalH = rows.length \* rowHeight

  * viewportBodyH = max(0, viewportH - headerH)

  * maxScrollY = max(0, bodyTotalH - viewportBodyH)

  * maxScrollX = max(0, contentWidth - viewportW)

* 绘制分层（都在 table 的 `save + translate(frame)` 坐标内）：

  1. `clipRect(0,0,viewportW,viewportH)`
  2. 背景（不跟随滚动）
  3. Header 层：`save → clipRect(0,0,viewportW,headerH) → translate(-scrollX,0) → draw header → restore`
  4. Body 层：`save → clipRect(0,headerH,viewportW,viewportH-headerH) → translate(-scrollX,-scrollY) → draw rows + body grid → restore`

     * 行渲染优化：从 `startRow=floor(scrollY/rowHeight)` 起，只画 `ceil(viewportBodyH/rowHeight)+1` 行
  5. 画 table 滚动条：

     * 竖条放在 body 区域右侧（y=headerH，高度=viewportBodyH）

     * 横条放在底部（y=viewportH-thickness），宽度=viewportW（可留出竖条空间）
